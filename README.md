### Flagship Project: Aerogis-Sentinel

> **Autonomous Network Defense & Threat Mitigation System**

[Aerogis-Sentinel](https://github.com/Doofusnotexpected/Aerogis-Sentinel) is an asynchronous cybersecurity honeypot designed to detect, analyze, and neutralize high-volume network brute-force attacks in real time without introducing firewall latency.

| Focus Area | Technical Implementation |
| :--- | :--- |
| **Core Architecture** | Asynchronous multi-threaded defense engine with local DeepSeek-R1 threat analysis |
| **Mitigation System** | Kernel-level IP exile, RAM-disk state tracking, zero-copy packet evaluation |
| **Validated Benchmark** | Neutralized 16-thread Hydra brute-force swarm against a 14.3M password dictionary |
| **Active Target** | Aerogis v13 — High-density threat vector evaluation & accelerated local LLM inference |
