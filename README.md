### 🛡️ About & Defensive Focus

Computer Science undergraduate focusing on **Defensive Cyber Engineering**, **Active Network Security**, and **Low-Level Systems Software**. My primary work centers on engineering resilient defensive tools—specifically localized honeypots, stateful logging systems, and automated threat detection pipelines—designed to withstand high-volume network traffic with minimal latency.

* **Core Focus:** Active threat mitigation, honeypot telemetry, network security, and low-level system design.
* **Engineering Philosophy:** Minimal attack surface, zero unnecessary bloat, and low-overhead execution.

### 🚀 Flagship Project: Aerogis-Sentinel

> **Autonomous Honeypot & Active Network Defense Perimeter**

Aerogis-Sentinel is an asynchronous, high-throughput network honeypot built to detect and mitigate brute-force attacks in real time without introducing firewall latency.

| Key Area | Technical Implementation |
| :--- | :--- |
| **Domain** | Network Defense, Threat Telemetry & Active Mitigation |
| **Architecture** | Asynchronous multi-threaded defense matrix with local DeepSeek-R1 analysis |
| **Mitigation Engine** | Instant IP exile, RAM-disk state tracking, zero-copy packet evaluation |
| **Validated Benchmark** | Neutralized a 16-threaded Hydra brute-force swarm against a 14.3M password dictionary |
| **Next Target** | Aerogis v13 — High-density threat vector evaluation & accelerated local LLM inference |
