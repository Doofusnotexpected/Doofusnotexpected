### 🛡️ About Me & Defensive Mindset

I am a Computer Science undergraduate at Telkom University focusing on **Blue Team Cyber Engineering**, **Active Threat Mitigation**, and **Low-Level Systems Development**. My primary passion lies in building high-throughput defensive infrastructure—specifically localized honeypots, stateful network logging engines, and automated threat forensics—designed to absorb, analyze, and neutralize hostility without burdening core system resources.

* **Blue Team Core Focus:** Active network defense, real-time incident response automation, honeypot telemetry, and local LLM threat analysis.
* **Red Team Perspective:** Utilizing offensive attack methodology (brute-force swarms, protocol fuzzing, vector analysis) solely to benchmark, harden, and validate defensive software resilience.
* **Engineering Standard:** Zero bloat, asynchronous low-latency execution, minimal attack surface area.

### 🚀 Flagship Platform: Aerogis-Sentinel

> **Autonomous Blue Team Honeypot & Active Defense Perimeter**

Aerogis-Sentinel is an asynchronous cybersecurity honeypot built to mitigate high-volume brute-force swarms in real time. By merging kernel-level IP exile, persistent RAM-disk telemetry tracking, and localized DeepSeek-R1 inference, it provides active defense without adding overhead latency to production firewalls.

| Metric | Specification |
| :--- | :--- |
| **Domain** | Blue Team Network Defense, Active Honeypot, Threat Telemetry |
| **Architecture** | Asynchronous multi-threaded matrix with local DeepSeek-R1 threat analysis |
| **Mitigation Engine** | Instant kernel-level IP exile, RAM-disk stateful SQLite tracking, zero-copy packet evaluation |
| **Benchmark** | Neutralized a 16-threaded Hydra brute-force swarm targeting a 14.3M password dictionary (v12.1 Core) |
| **Staging Target** | **Aerogis v13:** High-density threat vector processing & accelerated local LLM inference |
