### Flagship Project: Aerogis-Sentinel

> **Asynchronous Honeypot & Active Network Defense Platform** — [View Source Code](https://github.com/Doofusnotexpected/Aerogis-Sentinel)

Aerogis-Sentinel is an autonomous, high-throughput active defense system engineered to detect and mitigate brute-force attack swarms in real time without introducing firewall overhead.

* **Core Architecture:** Multi-threaded asynchronous event loop integrated with localized DeepSeek-R1 threat analysis.
* **Mitigation Engine:** Instant kernel-level IP exile, RAM-disk stateful SQLite tracking, and zero-copy packet evaluation.
* **Validated Benchmark:** Neutralized a 16-threaded Hydra brute-force swarm against a 14.3M password dictionary.
