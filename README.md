### 🛡️ About Me & Blue Team Focus

I am a Computer Science student at Telkom University focusing on **Blue Team Defensive Security**, **Application Security (AppSec)**, and **Low-Level Systems Engineering**. My core engineering discipline revolves around designing active defense platforms, low-latency network monitors, and stateful intrusion mitigation cells capable of analyzing hostile attack traffic under load.

* **Defensive Systems Paradigm:** Modern network defense must be proactive, stateful, and autonomous. Traditional firewall rules are reactive; true defensive engineering requires sub-millisecond threat vector isolation, real-time log heuristics, and minimal resource footprint.
* **Blue Team Core Focus:** Building active honeypots, stateful IP exile engines, asynchronous telemetry processors, and edge security tooling that integrates lightweight local machine learning for automated packet classification.
* **Engineering Standard:** Zero unneeded dependencies, minimal attack surface, optimized memory allocation, and high-concurrency event loops engineered in C++ and Python.

### 📡 Flagship Platform: Aerogis-Sentinel

> **Autonomous Active Defense Cell & High-Throughput Cybersecurity Honeypot**

**[Aerogis-Sentinel](https://github.com/Doofusnotexpected/Aerogis-Sentinel)** is an asynchronous, high-concurrency security engine built to capture, evaluate, and neutralize malicious brute-force swarms in real time. Designed specifically to alleviate host firewall processing queues, it acts as an intelligent perimeter shield that intercepts high-frequency attack patterns without inducing latency on legitimate services.

#### ⚙️ Technical Architecture & Pipeline

```
[ Inbound Network Traffic ]
            │
            ▼
[ Asynchronous Socket Listener ] ───► Zero-Copy Packet Inspection
            │
            ▼
[ Stateful SQLite RAM-Disk Engine ] ───► Rate Threshold & Vector Verification
            │
            ├──► (Known Threat) ───► Instant Kernel IP Exile (iptables/nftables)
            │
            └──► (Complex Anomaly) ───► Local DeepSeek-R1 LLM Telemetry Analysis
```
