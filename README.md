### 🛡️ About Me & Defensive Systems Focus

I am a Computer Science student at Telkom University specializing in **Cybersecurity**, **Application Security (AppSec)**, and **Low-Level Systems Software**. My engineering focus centers entirely on building robust defensive security tooling—specifically localized honeypot architectures, active network mitigation pipelines, and real-time threat intelligence engines designed to operate under heavy concurrency with zero latency bloat.

* **Primary Engineering Field:** Active network defense, real-time threat analysis, honeypot telemetry, and local LLM forensic pipelines.
* **Security Mindset:** Using offensive attack techniques strictly to stress-test, benchmark, and harden defensive code against active brute-force vectors.
* **Design Philosophy:** Minimal attack surface area, asynchronous low-latency execution, clean memory usage.

### 🚀 Flagship Platform: Aerogis-Sentinel

> **Autonomous Cybersecurity Honeypot & Active Network Defense Engine**

[Aerogis-Sentinel](https://github.com/Doofusnotexpected/Aerogis-Sentinel) is an asynchronous network defense honeypot built to neutralize high-volume brute-force attacks in real time without adding latency overhead to host firewalls.

| Core Architecture | Technical Details |
| :--- | :--- |
| **Security Domain** | Active Network Defense, Honeypot Infrastructure & Threat Intelligence |
| **System Architecture** | Asynchronous multi-threaded defense engine integrated with localized DeepSeek-R1 inference |
| **Mitigation Engine** | Instant kernel-level IP exile, RAM-disk stateful SQLite tracking, zero-copy packet processing |
| **Stress Benchmark** | Neutralized a 16-thread Hydra brute-force swarm targeting a 14.3M password dictionary (v12.1 Core) |
